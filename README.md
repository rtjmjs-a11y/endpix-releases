# endpix Releases

公开 APK 发布仓库 - **只有 APK 和版本元数据**，主代码在 [endpix-c1](https://github.com/rtjmjs-a11y/endpix-c1) (private)。

## 下载最新版本

主人在 Android 设备上访问 release 页面下载 APK：

https://github.com/rtjmjs-a11y/endpix-releases/releases/latest

## 版本格式

`0.1-eYYMMDD.amNNN` 格式，例如 `0.1-e260821.am117t`

## 为什么单独建这个仓？

- 端主人个人使用 + 小范围分发的 endpix app
- 主代码 (endpix-c1) 保持 private (含 Vercel 端点 + Admin token)
- APK 公开下载方便主人 + 朋友快速装机
